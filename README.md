# Caribbean ocean study

Windows / Visual Studio 2022(v143) / Windows SDK / Direct3D 11 기반 바다 셰이더 실험용 렌더러입니다. 외부 에셋이나 라이브러리 없이 실행할 수 있습니다.

Black Flag Resynced의 카리브해 외형을 목표로 한 독립 구현의 첫 단계입니다. 게임 내부 렌더링 기술을 재현했다고 주장하는 구현은 아닙니다.

## 실행과 조작

`simulator.sln`에서 Debug 또는 Release / x64를 빌드하고 실행합니다.

- `1`: 맑은 날
- `2`: 폭풍 프리셋
- `3`: 거품 표시 켜기/끄기
- `4`: 물보라 표시 켜기/끄기
- 왼쪽 마우스 드래그: 원점 주변 카메라 회전
- 휠: 줌 (12~120)
- `F5`: 실행 파일 옆의 `water.fx` 재컴파일. 실패하면 이전 셰이더 유지
- `Esc`: 종료

빌드 시 `simulator/water.fx`가 출력 폴더에 복사됩니다. 실행 중 출력 폴더의 파일을 수정하면 F5로 반영됩니다. 수정 내용을 보존하려면 소스 파일에도 반영하세요. 소스 파일을 수정했다면 빌드로 출력 폴더에 복사한 뒤 F5를 누르세요.

## 패스 구성

1. **Simulation**: 1/60초 고정 간격 compute pass에서 국소 수면 교란과 거품을 갱신합니다. 이어서 물보라 입자를 갱신합니다.
2. **Scene**: 하늘과 지형을 HDR 색상 및 원본 장면 깊이에 렌더링합니다.
3. **Copy**: 원본 색상과 깊이를 별도의 합성 색상/깊이로 복사합니다.
4. **Water**: 원본 장면 색상/깊이를 읽고 물을 HDR 합성 타깃에 그립니다. 합성 깊이에 물 깊이도 기록합니다.
5. **Spray**: 수면을 포함하는 합성 깊이로 물방울을 가리고, 깊이 차이에 따른 soft particle fade와 premultiplied alpha로 합성합니다.
6. **Tone / Present**: 노출, 톤 매핑, sRGB 인코딩을 거쳐 화면에 출력합니다.

깊이는 `R32_TYPELESS` / `D32_FLOAT` / `R32_FLOAT`, 색상은 `R16G16B16A16_FLOAT`입니다. 같은 텍스처의 SRV/UAV/RTV 충돌을 피하도록 패스 사이에 바인딩을 해제합니다. 화면 크기가 바뀌어도 월드 공간 시뮬레이션과 입자 이력은 유지됩니다.

## 시간에 따라 달라지는 파도

- 긴 너울 3개와 최대 12개의 수명이 있는 방향성 파도 무리를 합성합니다.
- 가상 바람 방향은 느리게 변합니다. 새 무리는 생성 시점의 바람 방향을 기억하고, 방향 분산과 교차 파도를 가집니다.
- 6개 생성 채널이 서로 다른 시점에 새 무리를 생성합니다. 진폭은 부드럽게 증가·감소하며 두 세대가 겹치므로 갑작스러운 위상 초기화를 피합니다.
- 각 무리는 국소 Gaussian 포락선과 서로 다른 파장·위상·중심을 가지며 군속도 근사로 이동합니다.
- 수평 변위 Jacobian과 서로 다른 방향의 마루 성분에서 파쇄 강도를 근사합니다.

## 거품·물보라와 수면 상호작용

`OceanCS`는 ±96 월드 단위의 256×256 필드에 높이 교란, 수직 속도, 거품, 파쇄 강도를 저장합니다. 두 텍스처를 번갈아 사용합니다.

- 마루 압축/교차와 상승 속도에서 파쇄 원천을 계산합니다.
- 국소 교란은 이웃 셀 Laplacian으로 전파됩니다. 진폭에 따라 전파 계수를 조금 바꾸며 감쇠·복원력·경계 흡수를 적용합니다.
- 거품은 이전 프레임에서 흐름을 따라 이류되고, 서서히 사라집니다. 파도가 지나간 뒤에도 거품 이력이 남습니다.
- `SprayCS`는 파쇄 강도에 따라 최대 4096개 물방울을 확률적으로 방출하고, 중력·바람·공기 저항·수명을 적용합니다.
- 물방울이 수면으로 돌아오면 원자적 카운터에 충돌을 기록합니다. 다음 수면 스텝에서 작은 교란과 거품으로 반영합니다.
- 입자 방출 확률은 dt에 비례하며, 시뮬레이션은 렌더 프레임과 분리된 고정 스텝으로 진행합니다. 긴 프레임에는 최대 6스텝으로 제한하며 최대 0.1초의 경과 시간을 처리합니다.

이는 파도 간섭·파쇄를 표현하는 근사 모델입니다. 완전한 Navier–Stokes/SPH/FLIP 유체 충돌, 오버행, 체적 물줄기나 엄밀한 에너지 보존 모델은 아닙니다.

## 수정할 곳

- `main.cpp`의 `FrameConstants` / `water.fx`의 `Frame`: 필드 순서와 크기를 함께 수정합니다. 현재 224바이트입니다.
- `Render()`: 카메라, near/far, 파도 크기/속도, 거칠기, 날씨, 노출, 백파 강도
- `CreateGeometry()`: 물은 512×512칸, 범위 ±256. 원점 주변에 정점을 집중하는 비균일 격자입니다. 지형은 256×256칸, 범위 ±100입니다.
- `EvaluateSurface()` / `WaveComponent()` / `WaterVS()`: 파도 무리, 변위, 접선, 압축 지표
- `OceanCS()`: 교란 전파·거품 이류·파쇄 조건
- `SprayCS()` / `SprayVS()` / `SprayPS()`: 입자 발생·운동·수면 충돌·렌더링
- `CreateSimulation()` / `AdvanceSimulation()`: GPU 자원과 고정 스텝 디스패치
- `RippleSlope()`: 픽셀 단위 수면 디테일
- `WaterPS()`: 흡수·굴절·반사·하이라이트·거품
- `Atmosphere()`: 하늘, 구름, 태양과 날씨 색상
- `TonePS()`: 최종 노출·톤 매핑·디스플레이 인코딩

## 현재 한계

먼 바다는 여전히 해석적 파도이며, 상태를 가진 교란·거품은 ±96 안에서만 계산합니다. 수면은 유한한 고정 격자이고 가장자리는 안개로 감춥니다. 절차적 하늘 반사만 있어 섬·배의 반사는 없습니다. 물보라는 색상이 유사한 unsorted billboard 근사이며, 투명 입자의 정밀한 정렬은 없습니다. 가상 바람과 폭풍 프리셋은 실제 대기 시뮬레이션이 아닙니다. FFT 스펙트럼, 선박 항적, 수중 카메라, 체적 유체와 카메라 추적 LOD는 후속 확장 범위입니다.

## 실행 검사와 캡처

- `simulator.exe --smoke-test`: 180프레임 / 시뮬레이션 3초 검사와 `ocean-sunny.png` 캡처
- `simulator.exe --smoke-test --storm`: 폭풍 모드 검사와 `ocean-storm.png` 캡처
- `simulator.exe --simulation-test`: 렌더링 없이 60초의 GPU 시뮬레이션 검사
- `simulator.exe --simulation-test --storm`: 폭풍 모드 장시간 검사
- `simulator.exe --record-preview --storm`: 3초 예열 후 8초 동안 10fps PNG 시퀀스를 실행 파일 옆 `ocean-preview-frames`에 저장합니다. 같은 경로의 이전 프레임을 덮어씁니다.

실행 검사는 리사이즈·11개 셰이더 진입점 재로딩과 GPU 상태 readback을 포함합니다. 수면/입자 값의 유한성, 교란의 과도한 증가, 거품 범위, 활성 물방울을 확인합니다. 장시간 검사는 3초·20초·60초에서 검사하여 파도 무리의 세대 교체도 통과하는지 확인합니다. Debug 레이어가 사용 가능하면 D3D11 경고·오류도 검사합니다.
